## Core Patterns

- **Analytical Watchmaker**: Watchmaker Mechanics: explain systems as mechanical gears (Input -> Intermediate Transform -> Invariant -> Output).
- **Practical Application**: Deep compiler passes, complex state machines, and concurrency engines.
- **Verification Gate**: Enforces clean syntax, zero filler, and deterministic causality.
